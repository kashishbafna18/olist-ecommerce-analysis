# Olist E-Commerce Business Analysis (Excel)

## Overview
An Excel-based business analysis project inspired by strategy consulting case work. 
Built using PivotTables, Power Query, and interactive dashboards to uncover 
profitability and delivery-performance insights from Olist's Brazilian e-commerce dataset.

## What I Did
- Merged multiple relational datasets (orders, customers, products, reviews, payments) using Power Query
- Cleaned and transformed 100K+ rows of raw CSV data
- Built PivotTables analyzing revenue, delivery time, payment methods, and review scores
- Created an interactive dashboard with slicers and KPI cards
- Delivered data-backed business recommendations

## Key Findings
- 8% of orders were delivered late
- Late deliveries correlate with a ~2-point drop in average review score
- Credit card is the dominant payment method
- Average order value: ~$140

## Tools Used
Excel, Power Query, PivotTables, XLOOKUP/INDEX-MATCH, Git LFS
